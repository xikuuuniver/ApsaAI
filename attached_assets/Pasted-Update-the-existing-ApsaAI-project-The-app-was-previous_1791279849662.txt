## 1. Desktop-first layout

Redesign the main chat interface for PC/Desktop.

The layout should have:

* A fixed/structured **left sidebar**
* The main **chat area on the right**

The current chat UI contains:

> Nexus Pro
> Enterprise thinking engine

Do not remove unrelated functionality connected to the chat engine.

## 2. Sidebar

Create a clean, modern ApsaAI sidebar on the left.

At the very top of the sidebar, display:

**ApsaAI**

Make the ApsaAI text large and bold so it clearly acts as the primary sidebar branding.

Directly underneath it, add these navigation options:

* New Chat
* Image
* Library
* Plugin
* Archive
* Private

Use the existing design system/components where possible and keep the UI consistent with the rest of ApsaAI.

## 3. Recent chat sessions

Below the main navigation options, display the user's recent chat sessions.

Each chat session should have:

* Chat/session title
* A three-dot menu button
* A pin icon/action

The chat list should remain scrollable if there are many sessions.

Do not break the existing chat-history functionality.

## 4. Chat session menu

When the user clicks the three-dot menu on a chat session, open a dropdown menu.

The dropdown must contain:

1. Rename
2. Pin Chat
3. Move to Private
4. Archive

These actions should work with the existing chat/session data and functionality.

The dropdown should appear cleanly beside the selected chat and should not cause the sidebar layout to jump or resize unexpectedly.

## 5. Pinned Chats

Implement a dedicated **Pinned Chats** section in the sidebar.

When a user pins a chat:

* That chat becomes part of the Pinned Chats section.
* The Pinned Chats section should appear near the top of the chat-history area.
* The pinned chat should NOT appear as a duplicate in the normal recent-chat list if the existing UX can support separating it cleanly.

### Important visibility rule

If there are **zero pinned chats**, completely hide the "Pinned Chats" section.

Do NOT show an empty:

> Pinned Chats

section.

Only display the section when at least one chat is actually pinned.

### Unpin behavior

Pinned chats must have an **unpin icon/action**.

When the user clicks the unpin action:

* Remove the chat from Pinned Chats.
* Return it to the normal recent-chat list.
* If there are now zero pinned chats, automatically hide the Pinned Chats section.

The pin/unpin state must persist correctly using the existing data/state system.
